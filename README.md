# 数字信号处理 · 复习要点与考题（笔记版）

一份可离线打开的单文件复习页，面向「数字信号处理」第 1—7 章的考前梳理：按章列出考点与页码，配 10 道考题及关键式提示，并把手写笔记整理成独立的「笔记」选项卡。

## 文件

```
数字信号处理-复习要点与考题-笔记版.html
```

单文件、无外部资源目录，双击即可用浏览器打开；不需要本地服务器。

## 页面结构

顶部三个选项卡切换，内容共用一套纸页版式：

| 选项卡 | 内容 | 适合什么时候看 |
| --- | --- | --- |
| 复习要点 | 第 1—7 章按章考点、教材页码、例题与课后题出处 | 第一遍过范围、核对老师划的重点 |
| 考题 | 10 道题的题干、题型标注、出处与关键式提示 | 考前对照练手，提示可一键隐藏 |
| 笔记 | 手写笔记整理：定义、推导、公式、对比表格 | 补推导细节，尤其是证明题 |

## 覆盖范围

- **第 1 章**：尺度变换（抽取与补零内插）、卷积的图解法与 δ 性质、单位脉冲响应
- **第 2 章**：DTFT 与 IDTFT 推导、Z 变换收敛域、留数法求逆、初值与终值定理、DTFT 对称性
- **第 3 章**：DFT 定义式的来源、与 Z 变换／DTFT 的关系、循环移位、循环卷积与频域卷积定理、对称性、频域采样定理及其证明
- **第 4 章**：DFT 与基 2 FFT 的运算量对比
- **第 5 章**：IIR 的直接Ⅰ型／直接Ⅱ型／级联／并联，FIR 的直接型与级联型
- **第 6 章**：巴特沃斯幅度平方特性、阶数与去归一化、脉冲响应不变法、双线性变换法与预畸变
- **第 7 章**：窗函数法与吉布斯效应

## 交互与排版

- **字号切换**：右上角按钮在 16 / 17.5 / 19 三档间循环，选择记在浏览器本地。
- **章节跳转**：各选项卡顶部的章节 chip 可直接跳到对应章节。
- **考题提示**：每道题下的关键式与要点默认展开，点「隐藏考点提示」可整页收起，方便自测。
- **公式**：使用 KaTeX 排版；断网或脚本被拦截时，公式自动回退为等价的纯文本写法，正文仍可读。
- **打印**：已内置打印样式，自动隐藏顶栏与跳转条，按 A4 分页时题目与公式块不会被截断。
- **窄屏**：手机与平板上单列排布，表格可横向滑动。

## 使用建议

1. 先看「复习要点」过一遍范围和页码，标出没印象的条目。
2. 用「考题」自测，先关掉提示独立写，再展开关键式核对推导步骤。
3. 证明题与推导题回到「笔记」看完整过程：IDTFT 的正交性、终值定理、频域采样定理四步、DFT 对称性。
4. 页码、例题编号与课后题号均以本课教材为准，复习时按自己手边的版本对照。
